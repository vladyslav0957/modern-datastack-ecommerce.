# Лабораторна робота №1: Видобуток та завантаження даних (ELT)

Проєкт з дисципліни "Технології сховищ даних". Індивідуальний варіант №14 ( Онлайн-кінотеатр ).

## Що тут зроблено
У цій роботі реалізовано первинний етап конвеєра даних (ELT):
1. Написано Python-скрипт (data_generator.py), який генерує імітаційні дані для кінотеатру (режисери, фільми, підписники, перегляди, відгуки) з додаванням "брудних даних" для майбутніх лабораторних.
2. Дані зберігаються локально у форматі .parquet (як озеро даних).
3. Розгорнуто базу даних PostgreSQL у контейнері Docker (docker-compose.yml).
4. Дані завантажуються в аналітичне сховище у схему aw безпосередньо з Python.

## Структура репозиторію
- **data_generator.py** — основний скрипт для генерації даних та заливки в базу.
- **data_generator.txt** — робочі нотатки / копія коду генератора.
- **docker-compose.yml** — конфігурація для запуску PostgreSQL у Docker.
- **docker-compose.txt** — додаткові налаштування або копія конфігу.
- **requirements.txt** — список використаних бібліотек (pandas, faker, sqlalchemy тощо).
- **.gitignore** — службовий файл для виключення зайвих папок (venv, __pycache__, data_lake).

## Як запутити проєкт
1. Створити та активувати віртуальне середовище:
   python -m venv venv
   venv\Scripts\activate

2. Встановити залежності:
   pip install -r requirements.txt

3. Підняти базу даних через Docker:
   docker compose up -d

4. Запустити генерацію та завантаження даних:
   python data_generator.py
