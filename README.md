# Modern Data Stack - Онлайн-кінотеатр (Лабораторна робота №1)

Комплексний інженерний проєкт у рамках дисципліни Технології сховищ даних (Індивідуальний варіант 14: Онлайн-кінотеатр).

## 1. Архітектура та Суть Проєкту
Проєкт реалізує сучасну парадигму ELT (Extract, Load, Transform). На першому етапі вирішуються завдання видобутку та завантаження транзакційних даних (OLTP) у сирий шар сховища даних:
- **Extract (Видобуток):** Генерація імітаційних даних за допомогою Python (Faker) для сутностей: directors, movies, subscribers, views, та 
reviews (з імітацією пропущених значень та бізнес-правил).
- **Data Lake (Озеро даних):** Збереження проміжних даних у форматі .parquet.
- **Load (Завантаження):** Первинне завантаження повного набору даних у схему 
raw аналітичного сховища (DWH) без трансформацій ("as is").
- **Інфраструктура:** Розгортання локального середовища бази даних PostgreSQL (версія 15) за допомогою контейнеризації Docker.

## 2. Структура репозиторію
- data_generator.py — основний Python-скрипт генерації даних та їх завантаження в DWH.
- docker-compose.yml — конфігурація для підняття контейнера PostgreSQL.
- requirements.txt — список необхідних бібліотек Python.
- .gitignore — файли та каталоги, які виключені з контролю версій.

## 3. Інструкція з запуску проєкту

Клонуйте репозиторій та створіть віртуальне середовище Python, після чого активуйте його:
'python -m venv venv'
'venv\Scripts\activate'

Встановіть необхідні залежності:
'pip install -r requirements.txt'

Запустіть локальне сховище у фоновому режимі через Docker:
'docker compose up -d'

Виконайте скрипт генерації та завантаження даних у Raw-шар:
'python data_generator.py'
