# Лабораторна робота №1: Видобуток та завантаження даних

## Суть проєкту
Реалізація первинного етапу інженерії даних (ELT) для онлайн-кінотеатру (варіант 14): генерація транзакційних даних за допомогою Python та їх завантаження у сховище даних без трансформацій у схему raw.

## Архітектура (Python -> Docker PostgreSQL)
1. Видобуток (Extract): Генерація імітаційних даних у скрипті data_generator.py для сутностей: режисери, фільми, підписники, перегляди, відгуки.
2. Озеро даних (Data Lake): Проміжне збереження даних локально у форматі parquet.
3. Завантаження (Load): Перенесення даних із Python у реляційну базу даних PostgreSQL, яка розгорнута в ізольованому контейнері через Docker.

## Інструкція з запуску проєкту
1. Створити та активувати віртуальне середовище Python:
python -m venv venv
venv\Scripts\activate

2. Встановити необхідні залежності:
pip install -r requirements.txt

3. Запустити локальну базу даних PostgreSQL у фоновому режимі через Docker:
docker compose up -d

4. Виконати скрипт генерації та завантаження даних:
python data_generator.py
